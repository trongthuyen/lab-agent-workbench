# @lab-agent-workbench/lawb

CLI for Lab Agent Workbench.

```bash
npx @lab-agent-workbench/lawb init --profile nestjs   # writes .lawb/config.json
npx @lab-agent-workbench/lawb config                  # prints the resolved config
```

`init` writes a snapshot of the resolved configuration; rerun it with `--force` to pick up
newer defaults. This is a v0.1 prototype. See the
[repository](https://github.com/trongthuyen/lab-agent-workbench).
